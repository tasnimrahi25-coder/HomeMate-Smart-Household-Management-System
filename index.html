How data flows

HomeMate is not a set of separate tools. The modules hand work to each other.

1 Add to the grocery list Plan what the household needs and set an optional price.
2 Tick it as purchased The purchase is written to your shared expense collection.
3 Budget updates The budget tracker recalculates spending and remaining balance.
4 Dashboard reflects it Totals, categories and pending items refresh in real time.
